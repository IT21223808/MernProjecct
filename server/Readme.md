This is a MERN Project Developed to Manage the students with the admin previledges.

Tailwind css is used for the styling of the application.


To run the application,
1. install the nodemodules by using npm i (for both frontend and server).
2. type nodemon app.js for the frontend and node server.js for the backend to start.
